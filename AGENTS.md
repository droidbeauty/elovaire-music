# UI copy

For requested UI design, refinement, or redesign work, read `UI_DESIGN_GUIDELINES.md` and apply it in conjunction with the user's specific brief and the existing app design system.

- English interface strings must not end with a period, whether they contain one sentence or several
- For a string with multiple sentences, use one sentence-separating period after the first sentence and omit the final period; rephrase additional clauses without losing meaning
- Preserve meaningful punctuation such as decimal points, abbreviations, URLs, question marks, exclamation marks, and ellipses
- Translate new user-facing copy, including accessibility descriptions, for every supported in-app language
- Changelog entry content remains English in every app language; surrounding changelog UI may be localized
